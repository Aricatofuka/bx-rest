Подключайте тестовый портал. Запросы уходят прямо с этой страницы на ваш портал. Подключение вместе с токеном или вебхуком сохраняется в localStorage браузера, а оно общее для всех страниц этого домена.

Установить демо в портал как приложение нельзя: Bitrix24 открывает приложение POST-запросом, а GitHub Pages такие запросы не принимает. Подключайтесь через вебхук или access-токен.

Connect a test portal. Requests go straight from this page to your portal. The connection, including the token or webhook, is saved in the browser's localStorage, which is shared by every page on this domain.

The demo cannot be installed in a portal as an app: Bitrix24 opens apps with a POST request, and GitHub Pages does not accept those. Connect with a webhook or an access token.
