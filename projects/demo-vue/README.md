# bx-rest — демо на Vue

Живой пример использования [`bx-rest`](../bx-rest) в Vue 3-приложении:
подключение к порталу Bitrix24, редактор кода на Monaco с
автодополнением по типам библиотеки и панель результата, которая реально
выполняет написанный код против вашего портала.

Интеграция сделана по образцу README библиотеки, раздел «Использование в
Vue»: [src/bxRestPlugin.ts](src/bxRestPlugin.ts) — тот же Vue-плагин,
регистрируется через `app.use(bxRestPlugin)` в `main.ts`. В отличие от
статичного примера в README, здесь портал/токен вводит пользователь, поэтому
`BXRestSettings.update(...)` вызывается не в `install()`, а реактивно —
при нажатии «Подключить» (см. `applyConnection` из `bx-rest-demo-shared`).
Экземпляр `bxRest` доступен и через `app.config.globalProperties` (как в
README, для Options API), и через `provide`/`inject` — им пользуются
компоненты на `<script setup>` в этом демо.

## Запуск

Из корня репозитория (нужно один раз собрать библиотеку и общий пакет демо):

```shell
npm run demo:bootstrap
```

Либо вручную:

```shell
# из корня репозитория
npm run build

# здесь
npm install
npm run dev
```

## Как пользоваться

1. Выберите режим авторизации — доступны все варианты из README библиотеки,
   раздел «Аутентификация и OAuth2» (access-токен функцией/localStorage/cookie,
   входящий вебхук, встроенная сессия Bitrix, OAuth2 через cookie). Для
   localStorage/cookie-режимов демо само пишет введённое значение в
   соответствующее хранилище браузера при подключении; «встроенная сессия» и
   «OAuth2 через cookie» по-настоящему работают только внутри iframe Bitrix24
   или с поддержкой credentialed CORS соответственно — подсказка под формой
   об этом предупреждает.
2. Укажите URL портала (кроме режима «Входящий вебхук» — там свой полный URL)
   и нажмите «Подключить». Сохраняется только в localStorage браузера.
3. Выберите готовый пример над редактором или напишите свой код, используя
   `bxRest.*` — Monaco подскажет доступные методы и поля параметров.
4. Заверните результат в `show(...)` и нажмите «Запустить».

Язык интерфейса определяется автоматически по `navigator.language`
(русский — если он русский, иначе английский), без переключателя — см.
`bx-rest-demo-shared/src/i18n.ts`.
